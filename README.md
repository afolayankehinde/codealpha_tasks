# CodeAlpha C++ Programming Internship Tasks

Tasks completed for the CodeAlpha C++ Programming internship (October batch).

## Tasks
1. **CGPA Calculator** (`Task1_CGPACalculator`): calculates each semester's GPA and the overall CGPA from course grades and credit hours.
2. **Login and Registration System** (`Task2_LoginSystem`): registers users, checks for duplicate usernames, validates input, saves scrambled passwords to a file and logs users in.
3. **Banking System** (`Task3_BankingSystem`): uses classes for customers, accounts and transactions, with deposits, withdrawals, transfers and transaction history.

## Separate repositories
Each task also has its own repository with a detailed README:
- [CGPA Calculator](https://github.com/afolayankehinde/CodeAlpha_CGPACalculator)
- [Login System](https://github.com/afolayankehinde/CodeAlpha_LoginSystem)
- [Banking System](https://github.com/afolayankehinde/CodeAlpha_BankingSystem)

## How to run any task
```
g++ filename.cpp -o program
./program
```
